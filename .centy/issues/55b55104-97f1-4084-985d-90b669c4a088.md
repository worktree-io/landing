# Stop overriding `default/no-hardcoded-urls` ESLint rule

The `default/no-hardcoded-urls` rule is currently disabled in `eslint.config.mjs` for all `src/**/*.{ts,tsx}` files because UI components contain hardcoded navigation links (e.g. GitHub URLs). We should stop overriding this rule and move hardcoded URLs to constants instead.

## Tasks

* [ ] Find all hardcoded URLs in `src/` files
* [ ] Extract them into named constants (e.g. in a `src/constants.ts` or co-located constants file)
* [ ] Replace inline URL strings with references to those constants
* [ ] Remove the `"default/no-hardcoded-urls": "off"` override from `eslint.config.mjs`
* [ ] Verify ESLint passes with no violations after the change
