# Stop overriding `max-lines-per-function` ESLint rule

The `max-lines-per-function` rule is currently disabled in `eslint.config.mjs` for all `src/**/*.{ts,tsx}` files because React component functions tend to be long. We should stop overriding this rule and comply with it instead by decomposing large functions.

## Tasks

* [ ] Identify all `src/` functions that exceed the `max-lines-per-function` limit defined by `eslint-config-agent`
* [ ] Extract sub-components or helpers to reduce function length
* [ ] Remove the `"max-lines-per-function": "off"` override from `eslint.config.mjs`
* [ ] Verify ESLint passes with no violations after the change
