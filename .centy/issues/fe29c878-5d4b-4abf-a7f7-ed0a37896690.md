# Mobile view support and e2e mobile testing

The landing page currently lacks responsive/mobile-optimized layouts. Ensure the site looks and works great on mobile viewports, and add mobile coverage to the existing e2e test suite.

## Tasks

### 1. Mobile-responsive layout

* Audit all sections (hero, how-it-works, install/action, pricing, footer) at common mobile breakpoints (320px, 375px, 390px, 430px)
* Fix any layout overflows, misaligned elements, or unreadable font sizes
* Ensure the nav/header is mobile-friendly (hamburger menu or collapsed layout if needed)
* Verify CTA buttons and code blocks are usable on touch screens
* Check spacing and padding scales correctly on small screens

### 2. E2E mobile testing

* Add a mobile viewport configuration to the Playwright setup (e.g. iPhone 13 / 390×844 and a mid-size Android like 412×915)
* Run the existing e2e tests against the mobile viewports to catch regressions
* Add mobile-specific snapshot baselines so visual diffs catch future mobile breakage
* Optionally add a test that asserts no horizontal scroll overflow exists on mobile
