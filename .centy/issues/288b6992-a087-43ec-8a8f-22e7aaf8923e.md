# CI/CD pipeline: deploy SSG site to Cloudflare Pages at worktree.io

Set up a GitHub Actions workflow that builds the Next.js site as a static export and deploys it to Cloudflare Pages, serving it under the custom domain worktree.io.

## Tasks

* [x] Ensure `next.config` has `output: 'export'` set so the build produces a static `out/` directory
* [ ] Create a Cloudflare Pages project (e.g. `worktree-io-landing`) via the Cloudflare dashboard
* [ ] Add the custom domain `worktree.io` to the Cloudflare Pages project and verify DNS records
* [ ] Add the following secrets to the GitHub repository settings:
  * `CLOUDFLARE_ACCOUNT_ID`
  * `CLOUDFLARE_API_TOKEN` (with Cloudflare Pages edit permissions)
* [x] Create `.github/workflows/deploy.yml` with a workflow that:
  * Triggers on push to `main`
  * Installs dependencies with `pnpm install`
  * Runs `pnpm build` to generate the static export
  * Deploys the `out/` directory to Cloudflare Pages using `cloudflare/pages-action`
* [ ] Confirm the deployment succeeds and `https://worktree.io` serves the latest build
* [x] (Optional) Add a preview deployment step that deploys PRs to a Cloudflare Pages preview URL
