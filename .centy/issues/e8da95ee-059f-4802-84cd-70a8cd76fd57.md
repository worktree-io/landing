# Replace inline SVG icons with an icon library

## Problem

The codebase contains many hand-drawn inline SVG icons scattered across 15+ files (e.g. `spawn-icon.tsx`, `how-it-works-icons.tsx`, `why-section.tsx`, `nav.tsx`, `hooks-section.tsx`, etc.). These are hard to maintain, inconsistent in style, and bloat JSX markup.

## Goal

Replace all inline `<svg>` icon elements with components from a proper icon library (e.g. [lucide-react](https://lucide.dev/), which is MIT-licensed, tree-shakeable, and has a comprehensive icon set). No icon library is currently installed.

## Tasks

- [ ] Choose and install an icon library (recommendation: `lucide-react` — it pairs well with Tailwind and already uses `currentColor` stroke style)
- [ ] Audit all 15 files that contain inline SVGs and map each icon to the closest equivalent from the library
- [ ] Replace inline SVGs in:
  - `src/app/spawn-icon.tsx` (custom hub/spoke icon — may need to keep as-is if no equivalent)
  - `src/app/how-it-works-icons.tsx` (InstallIcon, WorkflowIcon, CommentIcon, LinkIcon, TerminalIcon)
  - `src/app/why-section.tsx` (4 inline SVGs for benefit cards)
  - `src/app/nav.tsx`
  - `src/app/hooks-section.tsx`
  - `src/app/hooks-vars-col.tsx`
  - `src/app/hooks-config-col.tsx`
  - `src/app/hero.tsx`
  - `src/app/install-section.tsx`
  - `src/app/github-mockup.tsx`
  - `src/app/integration-block.tsx`
  - `src/app/copy-button.tsx`
  - `src/app/how-it-works.tsx`
  - `src/app/open/opening-view.tsx`
  - `src/app/open/no-params-view.tsx`
- [ ] Delete or consolidate `spawn-icon.tsx` and `how-it-works-icons.tsx` if fully replaced
- [ ] Verify the build passes (`pnpm build`) and visual snapshots are updated
