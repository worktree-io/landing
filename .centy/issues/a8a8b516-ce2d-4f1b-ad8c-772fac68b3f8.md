# Add pre-push hook to validate build and tests

Set up a pre-push git hook that runs the production build and the full Vitest test suite before allowing a push. This prevents broken builds or failing tests from reaching the remote repository.

## Tasks

* [ ] Install and configure a pre-push hook (via husky or simple shell script in `.husky/`)
* [ ] Add build validation step (`next build` or equivalent) to the pre-push hook
* [ ] Install and configure Vitest for unit/integration testing
* [ ] Add Vitest test run step to the pre-push hook
* [ ] Ensure the hook exits with a non-zero code on failure to block the push
* [ ] Provide clear error output so developers know which step failed
* [ ] Document the hook setup and how to skip it in emergencies (`--no-verify`)
