# Document pre:open and post:open hook config options (Mustache bash scripts)

## Context

The runner is gaining `[hooks] pre:open` and `post:open` config options that let
users run bash scripts with Mustache variables when a workspace is opened.
`pre:open` runs before the editor launches; `post:open` runs after.
The landing site / docs need to expose this feature to users.
