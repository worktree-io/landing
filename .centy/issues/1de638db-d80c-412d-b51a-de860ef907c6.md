# Auto-close /open page after 10s of inactivity with persistent toggle

After the worktree URL scheme is triggered on the `/open` page, if the user does not interact (click any button) within 10 seconds, the tab should automatically close itself via \`window.close()\`.

A toggle should be available to disable this behavior. The toggle state must be persisted in \`localStorage\` so the user's preference is remembered across visits.

## Tasks

* [ ] In \`opening-view.tsx\` (success phase), start a 10-second countdown when \`phase === "success"\`
* [ ] Display a visible countdown (e.g. "Closing in 5…") so the user knows what is happening
* [ ] On countdown completion, call \`window.close()\`
* [ ] Add a toggle UI element (checkbox or switch) labeled "Auto-close tab" visible during the success phase
* [ ] Read the initial toggle state from \`localStorage\` key \`worktree:auto-close\` (default: \`true\`)
* [ ] Persist toggle changes back to \`localStorage\` immediately on change
* [ ] When the toggle is turned off, cancel the active countdown timer
* [ ] When the toggle is turned back on, restart the 10-second countdown
