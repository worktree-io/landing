# Stop overriding `max-lines` ESLint rule

The `max-lines` rule is currently disabled in `eslint.config.mjs` for all `src/**/*.{ts,tsx}` files because UI component files tend to be long. We should stop overriding this rule and comply with it instead by splitting large files.

## Tasks

* [ ] Identify all `src/` files that exceed the `max-lines` limit defined by `eslint-config-agent`
* [ ] Split or refactor those files so each stays within the allowed line count
* [ ] Remove the `"max-lines": "off"` override from `eslint.config.mjs`
* [ ] Verify ESLint passes with no violations after the change
