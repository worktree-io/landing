# Stop overriding `no-restricted-syntax` ESLint rule

The `no-restricted-syntax` rule is currently disabled in `eslint.config.mjs` for all `src/**/*.{ts,tsx}` files. We should stop overriding this rule and comply with the syntax restrictions defined by `eslint-config-agent`.

## Tasks

* [ ] Review which syntax patterns `eslint-config-agent` restricts via `no-restricted-syntax`
* [ ] Find all usages of restricted syntax in `src/` and refactor them
* [ ] Remove the `"no-restricted-syntax": "off"` override from `eslint.config.mjs`
* [ ] Verify ESLint passes with no violations after the change
