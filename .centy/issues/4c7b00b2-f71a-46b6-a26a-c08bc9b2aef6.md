# Add screenshot testing for generated pages

Set up screenshot (visual regression) testing for the SSG-generated pages. After each build, capture screenshots of each page and compare them against stored baselines to detect unintended visual changes.

## Tasks

* [ ] Choose a screenshot testing tool (e.g. Playwright with `expect(page).toHaveScreenshot()`, or Storybook + Chromatic)
* [ ] Add a script to build the site and serve the static output locally (e.g. `next build && next start` or `serve ./out`)
* [ ] Write screenshot tests for each generated page (e.g. `/`, `/open`)
* [ ] Commit baseline screenshots to the repository
* [ ] Integrate screenshot tests into the pre-push hook (or CI) so regressions are caught before they land
* [ ] Document how to update baselines when intentional visual changes are made
