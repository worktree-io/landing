# Run e2e tests against Cloudflare Pages preview deployment

## Problem

The CI workflow already deploys to Cloudflare Pages and exposes a preview URL, but the e2e tests are not run in CI at all. The `playwright.config.ts` webServer is configured to build and serve locally:

````ts
webServer: {
  command: "pnpm run build && pnpm exec serve out -l 3000",
  url: "http://localhost:3000",
  reuseExistingServer: !CI,
},
````

## Desired Behaviour

Run the Playwright e2e tests in CI against the Cloudflare Pages preview URL (available as `steps.deploy.outputs.url` in `deploy.yml`) instead of starting a local server. This:

* Tests the actual deployed artefact rather than a locally-served copy
* Eliminates redundant local build + serve overhead in CI
* Catches deployment-specific issues (headers, routing, asset paths) early

## Implementation Notes

* Add a step to `deploy.yml` after the Cloudflare Pages deploy that runs `pnpm exec playwright test` with `BASE_URL` (or `PLAYWRIGHT_BASE_URL`) set to `${{ steps.deploy.outputs.url }}`
* Update `playwright.config.ts` to read `baseURL` from the env var when present, and skip the `webServer` block when a remote URL is provided
