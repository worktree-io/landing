# Stop overriding `jsx-classname/require-classname` ESLint rule

The `jsx-classname/require-classname` rule is currently disabled in `eslint.config.mjs` for all `src/**/*.{ts,tsx}` files because UI components use inline styles. We should stop overriding this rule and comply with it instead.

## Tasks

* [ ] Audit all `src/` components that use inline styles and replace with `className`-based styling
* [ ] Remove the `"jsx-classname/require-classname": "off"` override from `eslint.config.mjs`
* [ ] Verify ESLint passes with no violations after the change
